## 1. 한눈에 보는 변경 요약

v2와 수정안 대비 가장 큰 변화 15가지입니다. 자세한 내용은 각 장에 있습니다.

1. 자기분석 목표를 두 개로 고정: ① 인지 왜곡 교정, ② 성향·의지력 측정 → 설정 자동화와 맞춤 조언. 두 목표에 쓰이지 않는 데이터는 수집하지 않습니다.
2. 분석의 기본 단위가 하루에서 카드로 바뀌었습니다. 하루·주 지표는 코드가 카드 기록을 합산해서 만듭니다.
3. 탭이 5개(홈 · 카드 · 타이머 · 상담 · 분석)입니다. 타이머 세션 중에는 다른 탭으로 이동할 수 없습니다.
4. 카드 필수 입력은 ‘언제 + 체크리스트’ 두 개입니다. 첫 행동·최소 버전·자신감·외부 변수 대응·보상 칸은 삭제했습니다.
5. 카드 결과는 실행 축(의지)과 계획 축(계획 정확도) 두 축으로 판정합니다. 시간을 다 채웠는데 체크리스트가 남으면 ‘실패’가 아니라 ‘계획 과대’입니다.
6. 미루기를 다 쓰면 자동 삭제가 아니라 실패로 기록합니다. 실패도 원인 태그가 필수입니다.
7. 채찍은 카드 한 장 실패에 반응하지 않고 ‘재발 신호’(패턴)에만 반응합니다.
8. 당근/채찍은 의지력 지수로 결정합니다. 첫 2주는 온보딩 심리검사로 추정하고, 기록이 쌓이면 데이터로 넘어갑니다.
9. OS 앱 잠금이 아직 없어서, 4단계 강제 채찍은 앱 안에서 가능한 장치로 1차 구현합니다.
10. 목표 기능을 새로 만듭니다(WOOP 방식). 카테고리 자동 분류 기능은 목표 연결로 대체합니다.
11. 나무가 숲이 됩니다: 중심에 전체 나무 1그루, 둘레에 목표별 나무.
12. 성적은 목표에 걸린 시험에서만 수집합니다. 온보딩의 과목별 성적 입력은 삭제했습니다.
13. 학원 같은 고정 일정은 카드가 아니라 일정 블록입니다. 의지력과 순공 계산에서 빠집니다.
14. 통화는 사용자가 정한 시각에 하루 1회, ‘지난 통화 이후’를 기준으로 한 대본으로 진행합니다.
15. 인사이트 반응 버튼 처리 방식을 바꿨습니다: [틀렸어]를 눌러도 인사이트를 숨기지 않고 실험 제안으로 연결합니다(앱이 확증 편향을 거드는 것을 막기 위해).

## 2. 자기분석의 목표와 수집 원칙

[신규] 초기 기획에 대한 비판은 “자기분석으로 사용자가 무엇을 얻는지 불분명해서, 불필요한 것까지 수집하고 플로우가 매끄럽지 않다”는 것이었습니다. 그래서 자기분석의 목표를 두 개로 정했습니다.

| 목표                           | 내용                                                                        | 앱에서 하는 일                                                                               |
| ------------------------------ | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| ① 인지 왜곡 교정               | 계획 → 실행 → 회고 과정에서 생기는 자기편향(오류 목록 1~7범주)을 바로잡는다 | 사전 기록(카드·예측)과 사후 기록(결과·말)을 비교해서 보여주고, AI 상담에서 경향을 피드백한다 |
| ② 성향·의지력 측정 → 맞춤 관리 | 사용자의 특징과 의지력을 재서 설정과 조언을 맞춘다                          | 첫 2주는 심리검사, 이후에는 데이터로 설정을 자동 조정하고 당근/채찍 강도를 정한다            |

[유지] 핵심 사용자 경험은 그대로입니다. 사용자가 “이 앱이 나보다 나를 더 잘 아네?”라고 느끼는 순간이고, 이 순간은 ① 구체적인 숫자, ② 내가 믿던 것과 다른 의외성, ③ 바로 확인할 수 있는 근거가 함께 있을 때 생깁니다.

#### 수집 원칙

- [유지] 자동 수집 > 1탭 > 음성 > 글쓰기 순으로 우선한다.
- [신규] 모든 수집 항목은 목표 ① 또는 ②의 쓰임이 있어야 한다. 쓰임은 7장 표에 적었다.
- [변경] 하루 수동 입력 30초 원칙은 유지하되, ‘의도된 마찰’ 예외를 하나 둔다: 미루기 사유 100자.
- [유지] 숫자 계산은 코드가, 해석과 문장은 LLM이 맡는다.
- [유지] 비교 조건이 각각 5일 이상 쌓이기 전에는 ‘가설’로만 말한다.
- [신규] 사용자가 직접 바꾼 설정은 AI가 다시 덮어쓰지 않는다.

## 3. 앱 구조: 5탭

[변경] 기존 4탭(홈·카드·타이머·분석)에 상담 탭을 더했습니다. 설정은 홈 오른쪽 위에 있습니다.

| 탭     | 역할          | 주요 화면                                                                                       |
| ------ | ------------- | ----------------------------------------------------------------------------------------------- |
| 홈     | 하루의 시작점 | 하루 첫 컨디션·감정 태그, 숲, 지금/다음 카드와 [시작], 오늘 한 줄, 현재 관리 모드와 이유, 설정  |
| 카드   | 계획          | 목표 목록(최대 3개), 일·주 타임라인, 고정 일정 블록, 카드 만들기·고치기, 계획 패턴 안내         |
| 타이머 | 실행          | 대기 화면(다음 카드, [지금 시작], [놀기]) / 세션 화면(전체화면)                                 |
| 상담   | AI와 대화     | 오늘의 통화(예약 시각, 지난 통화 요약), 채팅, 목표 만들기 대화, 다짐 녹음 듣기, 일기(선택 기능) |
| 분석   | 나를 아는 곳  | 주간 리포트, 달력, 가설·인사이트, 자기 실험, 나 사용설명서, 상세 통계                           |

#### [신규] 타이머 잠금 규칙

- 공부 세션이나 놀기 세션이 진행 중이면(일시정지 포함) 하단 탭바를 숨기고 다른 탭으로 이동할 수 없다.
- 세션 화면을 나가는 길은 [일시정지] 또는 [끝내기]뿐이고, 둘 다 팝업을 거친다. 이 팝업이 곧 데이터 수집 지점이다.
- 휴대폰 홈 버튼으로 앱을 벗어나는 것은 막을 수 없다(OS 영역). 앱으로 돌아오면 항상 세션 화면으로 복귀한다.
- 세션이 없을 때 타이머 탭은 대기 화면이고, 다른 탭과 자유롭게 오갈 수 있다.

## 4. 기능 명세

### 4.1 온보딩 (약 3분) [변경]

v2의 5분 설문과 수정안의 심리검사·다짐 녹음이 겹쳐 진입 장벽이 높았습니다. 온보딩에는 설정에 꼭 필요한 것만 남기고, 목표와 관련된 입력은 첫 목표를 만들 때로 옮겼습니다.

1. 앱 소개 한 장: “이 앱은 너를 분석하는 앱이야. 사실과 다른 기록은 네 분석만 틀어지게 해.”
2. 학년: 고1 · 고2 · 고3 · N수 · 대학생 · 기타
3. 심리검사 14문항 (리커트 7점, 문항은 6장)
4. 자기 인식 4문항(선택형): 아침형/밤형/잘 모르겠음, 한 번에 집중 가능한 시간, 가장 큰 방해 요소, 평일 하루 공부 가능 시간. → ‘내 가설’로 저장해서 나중에 데이터로 확인하거나 반박한다.
5. 관리 설정: 통화 시각, 연락 금지 시간(기본 23:00~07:00), 수면 보호 시간(취침·기상, 최소 6시간), 제재 최대 한도, 말투 수위. 한도와 수위는 검사 결과로 AI가 기본값을 미리 채워두고, 사용자가 반드시 확인한다(명시적 동의).
6. 결과 화면: 성향 요약 3줄 + 자동 설정 요약(설정마다 이유 한 줄) + “2주 동안 네 가설을 확인해볼게.”
7. 첫 목표 만들기로 이동 (건너뛰기 가능).

[삭제] v2 온보딩의 과목별 성적·자신감, 주 공부 장소 / [변경] 목표 대학·점수와 공부 동기 → 목표 만들기, 과거 실패 경험 → 심리검사 문항, 학교·학원 시간표 → 고정 일정 입력

### 4.2 홈 [변경]

- 하루 첫 진입 태그: 컨디션 1~5 + 감정 태그(복수 선택: 막막함 · 불안함 · 피곤함 · 짜증남 · 평온함 · 의욕 있음). 1탭, 건너뛰기 가능.
- [신규] 알림을 눌러 타이머로 바로 들어오면 홈을 거치지 않는다. 그래서 그날 첫 화면이 어디든 맨 위에 같은 태그 한 줄을 띄운다. 건너뛰면 통화 때 묻는다.
- 태그의 쓰임: 막막함·불안함 → 그날 카드에 5초 카운트다운과 쪼개기 자동 활성화. 피곤함 → 유연 카드 축소를 1회 제안. 그리고 “컨디션 2라고 한 날도 평소의 90%는 했어” 같은 감정적 추론 반박의 재료.
- 숲(4.7), 지금/다음 카드와 [시작], 오늘 한 줄(AI 문장, 데이터 근거 1개), 현재 관리 모드와 이유 한 줄(예: “최근 3일 중 2일을 폰 때문에 놓쳐서 넛지 모드야”), 설정 아이콘.
- [신규] [지금 시작]: 카드 없이 바로 공부를 시작하면 ‘언제 = 지금’인 즉석 카드가 자동으로 생긴다. 제목과 체크리스트는 종료 팝업에서 한 줄로 받는다. 모든 세션이 카드에 붙어 있어야 분석이 깨지지 않는다.

### 4.3 카드 [변경]

#### 입력 항목

| 항목           | 필수/선택               | 기본값                            | 비고                                                                                              |
| -------------- | ----------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------- |
| 제목           | 필수                    | —                                 | 무엇을 하는지                                                                                     |
| 언제           | 필수                    | —                                 | 시작 시각 + 길이. 반복(요일) 또는 1회성. 플래너·캘린더·알람 앱의 인터페이스를 참고                |
| 체크리스트     | 필수                    | AI가 제목·목표·과거 기록으로 생성 | 개수 자유, 항목 간 중요도 구분 없음. 기록 부담이 낮은 사용자에게는 2주 뒤 “이번엔 직접 써볼까요?” |
| 목표 연결      | 선택                    | 최근 목표                         | ‘목표 없음’ 가능. 카테고리 기능을 대신함                                                          |
| 우선순위       | 선택                    | 유연                              | 절대(미룰 수 없음: 과제 제출 등) / 유연(운동 등)                                                  |
| 유형           | 선택                    | 자습                              | 자습 / 인강                                                                                       |
| 예상 달성 개수 | 선택                    | 체크리스트 전부                   | 낮추면 이유 태그 1개. 기본값 그대로 둬도 ‘예측’으로 저장됨                                        |
| 예상 실패 원인 | 선택 (성향에 따라 필수) | —                                 | 내 행동에서 나오는 원인을 1개 이상 포함. 처음엔 주관식, 기록이 쌓이면 AI가 선지 생성              |
| 알림           | 선택                    | 시작 정각, 메시지, 기본 문구      | 방식(메시지/전화), 몇 분 전, 문구를 직접 설정 가능                                                |

[삭제] 첫 행동, 최소 버전, 자신감(%), 외부 변수 대응, 보상, 즐거움 묶기 허용 범위

#### 규칙

- [유지] 수면 보호 시간(최소 6시간)과 겹치는 카드는 저장할 수 없다.
- [유지] 카드 사이에 여유가 없으면 10분 버퍼를 권한다.
- [변경] 우선순위는 드래그 대신 절대/유연 토글로 정한다. 절대 카드는 미루기 버튼이 없다. 일정이 넘치면 AI가 유연 카드부터 줄이자고 제안한다.
- [신규] 계획 시간 측정: 카드 편집 화면을 연 순간부터 저장할 때까지의 시간을 기록한다. → ‘계획 대 실행 비율’에 쓴다.
- [변경] 계획 패턴 안내: 카드 화면 아래에 같은 목표 카드의 최근 4주 체크리스트 달성률과 판정(과대 / 적정 / 느슨)을 보여준다. [상세 보기]를 누르면 과거 카드별 예측과 실제를 볼 수 있다.
- [신규] 고정 일정: 학교·학원은 카드가 아니라 일정 블록이다. 반복 입력하거나 캘린더에서 가져온다(연동 가능 여부는 개발 확인). 타이머가 없고, 의지력·순공 계산에서 빠진다. 공부 가능 시간 계산, 버퍼·수면 보호, “학원 늦게 끝난 다음 날” 패턴 분석에만 쓴다.
- 타임라인: 목표별 색, 절대 카드 표시, 고정 일정은 회색 블록.

### 4.4 타이머

#### 시작 [변경]

- 알림은 카드에 쓴 문장(또는 기본 문구) 그대로 온다. 누르면 사전 질문 없이 바로 세션 시작 화면으로 간다.
- 예정 시각 3분 뒤까지 시작하지 않으면 “6시 03분이야. 10분 기다리지 말고 지금 시작해요”처럼 현재 시각을 넣어 알린다. 선택지는 [시작] 하나뿐이다. [5분 뒤]는 없다.
- 미리 시작해도 된다.
- [변경] 카드 시간 안에 늦게 시작하면 지연 시간만 기록하고 미루기 횟수는 깎지 않는다. 예정 시각 10분 안에 시작하면 ‘정시 시작’으로 집계한다(지연 시간은 그대로 기록).
- [변경] 5초 카운트다운: 켜져 있으면 [시작]을 누른 뒤 체크리스트 첫 항목을 아주 작은 준비 행동으로 바꿔 보여준다(AI 제안, 예: “수학 문제집 42쪽 펴기”). 5초 동안 째깍 소리가 나고, 0이 되면 세션이 시작된다. [더 작게]로 최대 2번 더 쪼갤 수 있다. 켜지는 조건: 설정 ON(시작 저항이 높은 사용자 기본값) 또는 그날 감정 태그가 막막함·불안함.

#### 세션 [변경]

- 전체화면이고 다른 탭으로 이동할 수 없다(3장).
- 타이머는 카드의 예정 종료 시각까지 줄어든다(뒤 일정을 지키기 위해). 일찍 시작하면 그만큼 길어진다.
- 화면 모드: 미니멀(시간과 버튼만) / 체크리스트(체크할 때 시각·소리 피드백, 진행률 표시). 기본값은 성향으로 정하고 설정에서 바꿀 수 있다.
- 딴생각 주차장: 메모 버튼. 떠오른 걱정이나 할 일을 한 줄 쓰고 바로 돌아온다. 기본 ON/OFF는 성향으로 정한다.
- 인강 카드: 영상을 보러 다른 앱으로 나가도 세션이 유지된다.
- [신규] 오프라인 세션: 야자처럼 폰을 내야 할 때 시작 화면에서 [오프라인]을 고른다. 폰을 내고, 돌려받은 뒤 끝낸다. 시간은 앱이 잰다.

#### 일시정지 [유지]

- 완료가 아니라 잠깐 멈춤이다(화장실 등). 일시정지 시간은 실행 시간에서 뺀다.
- 팝업 태그(1탭): 화장실 · 물/간식 · 폰 확인 · 딴생각 · 막힘 · 외부 방해(가족 등) · 기타(글). 고정 태그는 코드가 내부/외부로 분류하고, ‘기타’의 글만 AI가 분류한다.
- 일시정지가 15분을 넘으면 복귀 알림을 한 번 보낸다.

#### 종료 [변경]

- 완료 기준은 예정 시간이 끝난 것이다. 중간에 [끝내기]를 누르면 ‘중도 종료’이고 실행률에 반영된다.
- 종료 팝업 (산출물 외에는 모두 1탭):
  - 체크리스트 최종 확인. 다 못 했으면 미달 사유 태그
  - 같이 한 것: 음악 / 영상 틀어둠 / 없음 (즐거움 묶기 기능을 대신함)
  - 산출물 증빙: 사진·링크·2~3줄 요약. 설정이 ‘선택’이면 나무 보너스, ‘강제’면 없을 때 실행으로 인정하지 않음
  - 잘 된 이유 태그: 체크리스트를 다 했을 때 3번에 1번(외부 귀인이 높은 사용자는 2번에 1번). 집중 잘 됨 · 계획이 적당함 · 컨디션 좋음 · 환경이 좋았음 · 누가 도와줌 · 운이 좋았음 → 내부/외부 분류
  - 다음 행동: [쉬기 → 놀기 타이머] / [다음 카드] / [닫기]

#### 미루기와 미실행 [변경]

- 미루기 버튼은 카드의 ⋯ 메뉴 안에 둔다(일부러 찾기 불편하게).
- 미루려면 ‘왜 미루는지 + 어떻게 할지’를 100자 이상 쓰고 새 시각을 정한다.
- 한도: 루틴 카드는 카드별 월 5회, 1회성 카드는 장당 2회. 성향에 따라 AI가 루틴 한도 3회를 권할 수 있다(사용자 확인). 절대 카드는 미루기가 없다. 관리 4단계에서는 미루기가 잠긴다.
- 카드 시간이 끝날 때까지 시작하지 않으면 알림을 보낸다: [미루기 (n회 남음)] / [실패로 기록].
- 실패에는 원인 태그가 필수다(1탭): 피곤·수면 · 아픔 · 행사·약속 · 계획 과다 · 폰·SNS · 하기 싫음 · 미루다 보니 · 기타.
- 미루기 횟수를 다 쓰면 [실패로 기록]만 남는다. [삭제] 자동 삭제는 없앴다. 하기 싫은 계획을 지우는 면죄부가 되기 때문이다.
- 아무 응답 없이 넘어가면 다음 통화에서 AI가 원인을 묻고 실패로 기록한다.
- 실패한 카드를 나눠서 다른 날에 넣을지는 ‘실패 직후’ 또는 ‘통화 때’ 처리한다(설정).

#### [신규] 사후 입력

- 오프라인 세션을 켜지 못했을 때를 위한 기능이다. 미리 만들어 둔 카드에만, 그날 다음 통화 전까지, 카드 예정 시간 이하로만 입력할 수 있다. 없던 세션을 새로 만들 수는 없다.
- 증빙(노트 사진, 인강 진도 캡처 등)이 있으면 일반 실행과 똑같이 취급한다. 없으면 ‘자기 보고’로 표시하고 의지력 계산에서 실행률 50%로 반영한다.
- 분석 탭에 측정 시간과 자기 보고 시간의 비율을 따로 보여준다.

#### [신규] 놀기 타이머

- 타이머 대기 화면의 [놀기] 또는 종료 팝업의 [쉬기]로 시작한다.
- 놀 시간(15 · 30 · 60분 · 직접 입력) + 태그(유튜브 · 게임 · SNS · 웹툰 · 쉬기 · 기타).
- 끝나기 1분 전 알림, 끝나면 알림과 함께 다음 카드 시작 화면을 연다(5초 카운트다운이 켜져 있으면 바로 연결).
- 놀기가 끝난 뒤 [카드 시작] 또는 [놀기 끝]을 누를 때까지의 시간을 ‘초과 휴식’으로 자동 기록한다.
- 놀기 세션 중에도 탭 이동은 막는다.

### 4.5 상담 [신규 탭]

#### 통화 [변경]

- 앱 안 음성 통화(구현 완료). 하루 1회, 사용자가 정한 시각에, 2~3분.
- 대본은 아침이든 밤이든 같은 구조로, ‘지난 통화 이후’를 기준으로 한다.

1. 결산: 실행한 카드, 실행률, 데이터 한 줄.
2. 처리 안 된 카드: 미실행 원인 확인, 실패 카드 분할 여부(설정이 ‘통화 때’일 때), 휴식 처리 여부.
3. 다음 통화까지의 카드 확인(특히 절대 카드).
4. 조건부 모듈 최대 1개. 우선순위: 안전 브레이크 > 회복 모드(What if) > 4칸 회고(재발 신호가 있을 때) > 목표 점검(2주마다) > 왜곡 경향 피드백(주 1~2회) > 예측 후 공개 질문.
5. 마무리: 통화 내용을 구조화 데이터로 저장하고 요약 카드를 남긴다.

- 그날 감정 태그가 없으면 1번 전에 묻는다.
- 통화를 못 받으면 상담 탭 채팅으로 같은 대본을 진행할 수 있다. 그것도 안 하면 다음에 앱을 열 때 1분짜리 요약 카드를 보여준다.
- [삭제] v2 체크인의 기분 5단계, 오늘 예상 순공, 오늘의 약속, 개선안 실천 여부 질문(실험 규칙은 카드 기록으로 자동 판정).

#### [신규] 4칸 회고

재발 신호가 있을 때 통화에 들어가는 모듈입니다. 격려 한 줄 뒤에 네 가지를 묻습니다.

| 칸          | 질문                                    | 목적                                      |
| ----------- | --------------------------------------- | ----------------------------------------- |
| ① 사실      | 무슨 일이 있었어?                       | 감정과 사실 분리                          |
| ② 내 선택   | 그때 내가 한 선택은 뭐였어?             | 내부 원인 찾기 (1번 오류)                 |
| ③ 대처      | 같은 상황이 또 오면 어떻게 할래?        | 다음 행동 정하기                          |
| ④ 카드 수정 | 카드를 어떻게 고칠까? (시간·체크리스트) | 답을 바로 카드 수정안으로 만들어 확인받음 |

#### 회복 모드 [변경]

- 켜지는 조건: 3일 연속 휴식·미실행, 부정적 감정 태그 3일 연속, 절대 카드 실패, 대화에서 힘들다는 표현. 민감도 기본값은 성향(실패 민감도)으로 정한다.
- 동작: 관리 단계 0, 나무가 시들지 않음, What if 기법(최악의 상황 상정 → 지금 할 수 있는 최선 찾기), 계획 축소 제안. 다음 날 다시 평가한다.

#### 휴식 처리 [변경]

- 미리 “오늘 쉴게”를 선언하는 기능은 없다. 불가항력(번아웃·아픔)으로 못 한 날을 사후에 ‘휴식’으로 처리한다.
- 월 4회까지. 휴식으로 처리한 날의 카드는 실패 집계와 의지력 계산에서 빠지고, 달력에 다른 색으로 표시된다.
- 분석에 휴식 횟수와 요일 패턴을 보여준다. 3일 연속이거나 월 한도를 넘으면 회복 모드와 기분 저하 점검으로 넘긴다.
- [삭제] 수정안의 “주 1~2일은 빠져도 되고 이틀 연속만 막는다” 규칙.

#### 채팅 · 일기 · 다짐

- 채팅: 통화 대본의 텍스트 버전 + 자유 상담. 시스템 프롬프트 규칙은 통화와 같다.
- [변경] 일기: 선택 기능(설정에서 켬). 자유 일기 + AI가 처방할 때만 정해진 기간·질문으로 쓰는 성찰일기. 원문은 본인만 보고, AI는 감정·원인·반복 키워드만 구조화한다.
- 다짐 녹음: 첫 목표를 만들 때 다짐 문장을 5번 외쳐 녹음한다. 상담 탭에서 언제든 다시 들을 수 있고, 관리 4단계에서는 카드 시작 전에 자동으로 재생된다.

#### AI 상담 공통 규칙 (시스템 프롬프트)

- [유지] 왜곡 표현(“그래도 ~는 했다”, “어제 열심히 했으니”, “~때문에”, “어차피”, “다들”)은 하나만 콕 집어 지적하지 않고, 쌓인 기록을 종합해 “~식으로 생각하는 경향이 있어”라고 피드백한다. 그리고 “내가 다르게 할 수 있었던 건?”으로 다시 말해보게 한다.
- [유지] 감정적이거나 내로남불식 판단을 할 때 “친구가 똑같은 일을 겪었다면 뭐라고 말해줄 것 같아?”라고 묻는다.
- [신규] 허위 합의(“다들 미뤄”)에는 보편성을 반박하지 않는다. “흔한 건 맞아. 근데 흔하다고 너한테 비용이 없는 건 아니야” + 본인 데이터를 보여준다.
- [유지] 지적은 행동에만 한다. 외모·성적·능력 비하와 다른 사람과의 비교는 금지. 왜 지금 이 모드인지 항상 말한다.
- [유지] 숫자는 코드가 계산한 값만 인용한다.

#### 안전 브레이크 [유지]

v2 그대로입니다. 위기 표현이 감지되면 모든 채찍을 즉시 멈추고 지지 모드로 바꾼 뒤 청소년상담 1388, 자살예방상담 109를 안내합니다. 연락 금지 시간 기본값은 23시~7시, 시험 직전 3일과 직후 2일은 채찍 상한이 2단계, 기분 저하가 5일 넘게 이어지면 회복 모드로 바꾸고 주변 어른이나 상담을 권합니다. [변경] 감지 범위를 통화·채팅·일기·미루기 사유·실패 사유의 글까지 넓혔습니다.

### 4.6 분석 [변경]

#### 주간 리포트: 하나로 합치고 칸을 고정

1. [신규] 예측 후 공개 1문항: 숫자를 보여주기 전에 사용자가 먼저 맞힌다. 예: “지난주 계획한 시간 중 실제로 공부한 건 몇 %였을 것 같아?” → 실제값과 차이를 보여준다. 질문은 실행률 · 평균 시작 지연 · 체크리스트 달성률 · 강의 대 자습 비율 중에서 돌아가며 낸다. 차이는 ‘예측 정확도’로 저장한다.
2. 숫자 3개
3. 인사이트 1개 (딴생각·핑계 패턴도 후보로 경쟁)
4. 지난 실험 결과
5. 다음 실험 제안

#### 나머지 화면

- [변경] 달력: 실행 · 지연 · 미실행 · 휴식을 같은 크기로 표시하고, 누르면 사유가 보인다. 감정도 표시한다. 연속 기록(스트릭) 강조는 없애고 최근 4주 실행률로 대신한다(스트릭은 성공만 기억하게 만들기 때문).

- [신규] 내 가설: 온보딩 자기 인식 4개를 AI 가설과 같은 방식으로 검증한다. 3일째와 7일째에 첫 확인을 보여줘서 첫 2주 공백을 메운다. 예: “3일 평균 시작 지연은 14분이야. 예상은 5분이었지?”

- 상세 통계: 딴생각 분류(#연락 #다른과제 #걱정 #생활), 핑계 패턴(자주 쓰는 핑계 TOP 3, 성공·실패별 내부/외부 귀인 비율), 목표별 계획 패턴, 강의 대 자습 시간, 측정 대 자기 보고 시간, 초과 휴식, 휴식 처리 패턴.
- [신규] 의지력 지수는 사용자에게 숫자로 보여주지 않는다. “의지력 42점” 같은 점수는 낙인(6번 오류)이 된다. 대신 행동 지표(정시 시작 비율 등)와 관리 모드의 이유로 보여준다.

#### 숲 [변경]

- 중심에 전체 나무 1그루: 모든 카드(자습·인강)의 실행 시간으로 자란다. 항상 가장 크다.
- 둘레에 목표 나무: 연결된 카드의 실행 시간으로 자란다. 목표가 끝나도 숲에 남는다. 지난 목표가 쌓일수록 숲이 넓어진다.
- 산출물 증빙이 있으면 성장 보너스.
- 잎: 회고와 인사이트 반응. 열매: 효과가 검증된 방법(전체 나무 = 나 사용설명서 항목, 목표 나무 = 그 목표 기간에 검증된 방법).
- 시듦: 재발 신호가 있을 때만 시든다(목표 나무는 그 목표의 카드 기준, 전체 나무는 전체 기준). 죽지 않고, 다시 실행하면 회복된다. 회복 모드에서는 시들지 않는다.
- 숲은 홈에, 성장 기록은 분석 탭에 보여준다.

### 4.8 설정 [변경]

- 거의 모든 설정을 AI가 성향으로 자동 세팅한다. 첫 2주는 심리검사, 이후에는 데이터가 기준이다(6장).
- 설정마다 ‘근거’(검사 기준 / 최근 데이터 기준)와 이유 한 줄, [되돌리기]를 붙인다.
- AI가 데이터를 보고 설정을 바꾸면 홈에 알린다. 예: “최근 시작이 늦어져서 5초 카운트다운을 켰어요 [되돌리기]”
- 사용자가 직접 바꾼 설정에는 잠금 표시를 하고, AI는 다시 바꾸지 않는다(제안만 한다).
- 자연어 설정: 원하는 것을 글로 쓰면 LLM이 변경안을 만들고, “이렇게 바꿀게요”로 확인받은 뒤 반영한다.
- 제재 최대 한도와 말투 수위는 AI가 바꾸지 않는다. 사용자만 바꿀 수 있다. 낮추면 즉시, 높이면 다음 날부터 적용한다.

## 5. 판정 규칙 [신규]

개발할 때 그대로 코드로 옮길 수 있도록 규칙을 적었습니다. 숫자는 모두 출발값입니다.

### 5.1 카드 결과

| 결과      | 조건                                                       | 쓰이는 곳                      |
| --------- | ---------------------------------------------------------- | ------------------------------ |
| 실행      | 예정 시각 10분 안에 시작, 예정 종료까지 진행               | 의지력, 나무                   |
| 지연 실행 | 10분 넘게 늦게 시작 (카드 시간 안)                         | 지연 시간 기록, 정시 시작 비율 |
| 중도 종료 | 예정 종료 전에 [끝내기]                                    | 실행률                         |
| 미루기    | 미루기 사용                                                | 미루기·실패 비율               |
| 실패      | 카드 시간이 끝날 때까지 미시작 → [실패로 기록] 또는 무응답 | 미루기·실패 비율, 재발 신호    |
| 휴식      | 사후 휴식 처리                                             | 모든 집계에서 제외             |
| 자기 보고 | 사후 입력                                                  | 증빙 없으면 실행률 50%         |

**실행률** = 실제 실행 시간(일시정지 제외) ÷ 계획 시간 (최대 1)

#### 계획 축 (체크리스트 달성률)

- 실행률 80% 이상인데 체크리스트가 남음 → 계획 과대. 채찍 재료가 아니라 계획 크기를 조정하는 재료다.
- 실행률 80% 미만이고 체크리스트가 남음 → 늦은 시작·중도 종료. 실행 축의 문제로 본다.
- 적정 구간: 최근 4주 체크리스트 달성률 70~90%. 90% 초과가 계속되면 ‘느슨’, 60% 미만이면 ‘과대’로 판정한다.
- 근거: 목표 설정 이론(Locke & Latham) — 어렵지만 달성 가능한 목표가 수행을 가장 높인다. 그리고 체크리스트가 남은 날을 ‘실패’라고 부르면 앱이 흑백 사고(6번 오류)를 직접 하게 된다.

### 5.2 재발 신호: 실수와 재발을 나눈다

근거: 재발 방지 치료(Marlatt)의 실수(lapse)·재발(relapse) 구분, 그리고 하루를 빠뜨려도 습관 형성에는 거의 영향이 없었다는 Lally 등(2010)의 연구입니다. 한 번의 실수를 크게 다루면 “이미 망쳤으니”(될 대로 되라 효과)로 번집니다. 최소 버전 기능을 삭제하면서 빠진 역할을 이 구분이 대신합니다.

- 카드 한 장 미실행 = 실수: 기록만 하고, 통화에서 한 줄 확인한다. 관리 단계는 움직이지 않는다.
- 재발 신호(하나라도 해당하면):
  - ① 같은 루틴 카드 2회 연속 미실행(미루기 또는 실패)
  - ② 최근 7일 실행률이 개인 기준선(직전 14일)의 70% 미만
  - ③ 절대 카드 미실행 1회
- 재발 신호가 오면: 관리 단계 판정(5.4), 통화에 4칸 회고, 나무 시듦.
- 고정 일정(학원 등)과 휴식 처리일은 계산에서 뺀다.

### 5.3 의지력 지수 (내부 값, 0~100)

#### 데이터 지수 (최근 14일, 자습·인강 카드만)

```
의지력(데이터) = 50 × 평균 실행률 + 30 × 정시 시작 비율 + 20 × (1 − 미루기·실패 비율)
```

#### 검사 추정 (온보딩 심리검사, 1~7점)

```
의지력(검사) = (7 − 시작 저항·주의 분산·실패 민감도의 평균) ÷ 6 × 100
```

#### 혼합

```
의지력 = w × 데이터 + (1 − w) × 검사,   w = min(유효 카드일 수 ÷ 14, 1)
```

- 평균 실행률: 카드별 실행률의 평균. 자기 보고(증빙 없음)는 0.5로 넣는다.
- 정시 시작 비율: 시작한 카드 중 예정 시각 10분 안에 시작한 비율.
- 미루기·실패 비율: 전체 카드 중 미루기 또는 실패가 된 비율.
- 유효 카드일: 카드가 1장 이상 있었던 날(휴식일 제외). 첫날은 검사 100%, 14일째부터 데이터 100%.
- 학원(고정 일정)은 의지력과 무관하므로 모든 항목에서 뺀다.
- 사용자에게 숫자로 보여주지 않는다(4.6).

### 5.4 관리 단계 (당근/채찍) [변경]

| 단계 | 이름                | 동작                                                                                                                                                                                                                                          |
| ---- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0    | 회복                | 위로, What if, 계획 축소 제안, 나무가 시들지 않음                                                                                                                                                                                             |

#### 기준 단계

의지력 70 이상 → 1단계, 40~69 → 2단계, 40 미만 → 3단계. 관리 선호가 높으면 +1, 낮으면 −1(1~3단계 안에서). 단, 첫 7일은 기준 단계 상한 2 — 기록이 없을 때는 채찍을 쓰지 않습니다.

#### 매일 1회 판정 (통화 시점, 통화가 없으면 다음 날 첫 진입 때)

1. 안전 조건(위기 표현, 기분 저하 5일 이상) → 0단계 고정, 안전 브레이크.
2. 회복 조건(4.5) → 0단계.
3. 재발 신호 + 주원인이 내부(폰·SNS, 하기 싫음, 미루다 보니) → 현재 단계 +1 (최대 4, 제재 한도 안에서).
4. 재발 신호 + 주원인이 불가피(아픔, 행사·약속) → 단계 유지, 계획 축소 제안.
5. 재발 신호 + 주원인이 계획 과다·피곤 → 단계 유지, 계획 축소 제안.
6. 재발 신호 없음 → 기준 단계 쪽으로 한 단계 이동.

- 주원인 = 해당 기간 미실행 원인 태그 중 가장 많은 것.
- 하루에 최대 한 단계만 올라간다. 성공(실행 + 체크리스트 70% 이상)하면 즉시 한 단계 내려간다(최소 1단계).
- 시험 직전 3일·직후 2일은 상한 2단계.
- 왜 이 단계인지 홈과 통화에서 항상 한 줄로 말한다.

### 8.2 7범주: 현실 점검을 피하는 왜곡 [신규]

팀이 정한 방식(과거 기록으로 편향을 짚기)을 기본으로 두 가지를 더했습니다.

- 피할 수 없는 곳에 넣는다: 7번 왜곡들은 공통적으로 ‘점검 자체를 피하는’ 것이라, 분석 탭에만 두면 정작 그 사람은 탭을 열지 않는다. 그래서 카드 만들 때, 통화, 주간 리포트 첫 화면에 넣는다.
- 지적하기 전에 먼저 맞혀보게 한다(예측 후 공개): 예측과 실제의 차이가 곧 왜곡의 크기라서 반박할 거리가 없고, 그 차이가 핵심 경험의 ‘의외성’이 된다. 예측 정확도가 쌓이면 메타인지 지표가 된다.

| 매몰 비용   | 효과 없다고 판정된 실험의 연장 요청, 진척 없는 목표 유지        | 실험 시작 전에 ‘그만둘 기준’을 미리 정하고 판정일엔 기준만 확인. 들인 노력은 나무로 남음. 2주마다 목표 점검                                    | 실험, 통화             |

#### 다음 버전

딴생각 AI 분류 리포트, 핑계 패턴 리포트(데이터는 MVP부터 수집), 일기, 구글 캘린더 연동, 전략 카탈로그 30~50개 확장, 9장의 보류 항목.

#### 개발 담당 확인 사항

1. 다른 앱의 사용 시간을 읽거나 앱을 잠글 수 있는 구조인지 (4단계 OS 잠금, 폰 사용 데이터)
2. 구글 캘린더 연동이 가능한지 (고정 일정 자동 입력)
3. 앱이 백그라운드에 있어도 타이머와 알림이 정확히 도는지 (인강·오프라인 세션)
4. 앱으로 돌아올 때 진행 중인 세션 화면으로 강제 복귀시킬 수 있는지 (탭 잠금)
5. 음성 녹음·재생을 이미 구현된 통화 기능과 같이 쓸 수 있는지 (다짐 녹음)

#### 팀 논의가 남은 것

- 심리검사 문항 표현 다듬기 (6.2)
- 전략 카탈로그 작성: MVP 10개 → 이후 30~50개 (v2 4장의 원인별 전략 예시에서 시작)

- 기준 숫자(70%, 80%, 10분, 월 5회, 월 4회 등)를 실제 데이터로 다시 볼 시점 정하기
- 앱 이름

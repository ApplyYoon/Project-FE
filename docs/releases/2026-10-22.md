## 1. 왜 했나

- 운영 화면이 통화 키를 BE 가 아니라 Vercel 함수(`api/voice-key.ts`)에서 받고 있었습니다. 그래서 통화 기록 번호(callId)가 없어 통화 결과가 저장되지 않았고, AI 는 학생 기록을 모른 채 고정 대본으로 계획부터 물었습니다. 그 함수는 로그인 확인 · 하루 한도도 없었습니다.
- 채팅 첫 답이 18초 걸렸습니다. 채팅방을 열며 만든 AI 인사(8.5초)가 화면에 안 쓰이고 버려졌습니다.
- 방끼리 이야기를 몰라서, 상담 방에서 미적분 이야기를 해도 계획 방은 과목 없는 계획을 만들었습니다.

## 2. 무엇이 바뀌었나 (화면)

### AI 통화

- **통화 키는 BE `POST /realtime/session` 에서만 받습니다.** `api/voice-key.ts` 와 `VITE_VOICE_KEY_URL` 을 지웠습니다. (`src/lib/realtimeCall.ts`)
- **잠금 화면을 없앴습니다.** 공부 전에도 홈 · 채팅 목록 · 상담 방에서 바로 통화합니다. 채팅 목록의 "잠김" 표시도 없앴고, 전화 알림도 공부와 상관없이 울립니다. (`CallPage` · `ChatListPage` · `useCallReminder` · `lib/checkCall.ts`)
- **홈 통화 입구**가 늘 보입니다. 공부 전엔 "AI 선생님한테 전화하기", 공부 뒤엔 "코치한테 3분 설명해 볼래?" (`HomePage`)
- **복습용 대기 인사말.** 끝낸 공부가 있으면 "'카드 제목' 끝냈구나! 나한테 설명해 줄래?" (`CallPage`)
- **공부 마무리 창** 마지막 단계의 첫 버튼이 [📞 확인 통화 받기] 입니다. (10분 넘게 공부했을 때, `CardTimerPage`)
- **테스트 로그인**으로 통화 화면에 오면 받기를 막고 "구글로 로그인하면 통화할 수 있어요" 를 보여 줍니다. 전화 알림도 테스트 로그인이면 울리지 않습니다.
- 통화 시간 표시는 서버가 주는 `maxCallSeconds` 를 그대로 써서 3분으로 나옵니다.

### 상담 채팅

- **첫 메시지는 인사 없이 채팅을 엽니다.** 채팅방이 없을 때 학생이 먼저 보내면 `POST /chats?greet=false` 로 채팅 번호만 받고 바로 메시지를 보냅니다. 주제로 여는 [이야기하기] 는 지금처럼 인사를 받습니다. (`lib/chatApi.ts` 의 `openChatSession`)
- **다른 방 이야기.** 오늘 다른 방에서 학생이 직접 쓴 말(방마다 3줄, 모두 6줄, 80자)을 채팅 말 보내기와 하루 계획 요청에 `otherRooms` 로 같이 보냅니다. 칩을 눌러 붙은 말 · 4자보다 짧은 대답은 뺍니다. (`lib/coachThread.ts` 의 `otherRoomLines`)

### 홈 · 학교 정보

- **주말에는 월요일 시간표 · 급식.** 서버가 주는 `schoolDay` 로 "월요일 시간표" · "월요일 중식" 처럼 적고(일요일엔 "내일"), "주말이라 다음 수업일 시간표를 미리 보여 줘요" 를 붙입니다. 코치 브리핑도 "월요일엔 … 수업이 있어" 로 말하고, 하루 계획의 "오늘 배운 과목" 에는 쓰지 않습니다. (`lib/schoolToday.ts` 의 `dayLabelOf`)
- 띄어쓰기 없는 긴 카드 제목이 통화 화면 밖으로 밀리지 않게 줄을 바꿉니다.

## 4. 알려진 제한 · 보류

- 테스트 로그인으로는 통화가 안 됩니다. 시연은 구글 로그인 계정으로 합니다.

- 소리 없이 하는 확인 퀴즈는 로컬 브랜치 `feat/silent-check-quiz` 에만 있고 올리지 않았습니다.

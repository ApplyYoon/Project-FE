---
description: 코드에 문제가 없는지 4가지 검사를 한번에 돌립니다
---

아래를 순서대로 실행하세요.

```bash
pnpm run typecheck
pnpm run lint
pnpm run format
pnpm run build
```

결과를 표로 간단히 보고하세요.

| 검사      | 결과 | 뜻                          |
| --------- | ---- | --------------------------- |
| typecheck | ✅   | 타입이 안 맞는 곳 없음      |
| lint      | ✅   | 위험한 코드 패턴 없음       |
| format    | ✅   | 코드 모양 정리 완료         |
| build     | ✅   | 실제 배포용으로 만들기 성공 |

실패한 것이 있으면:

1. **에러 메시지 원문**을 보여줍니다.
2. 그 에러가 **무슨 뜻인지 한국어 한 줄**로 풀어줍니다.
3. 어떻게 고칠지 제안하고, 간단한 것이면 바로 고칩니다.

설정을 끄거나 무시 주석으로 덮어서 통과시키지 마세요.

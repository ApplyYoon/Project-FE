---
description: 개발 서버를 켜서 브라우저에서 화면을 확인합니다
---

```bash
pnpm install
pnpm run dev
```

- 브라우저가 자동으로 열립니다. 안 열리면 http://localhost:5173 을 알려주세요.
- 화면을 고친 뒤에는 저장만 하면 브라우저가 알아서 새로고침됩니다.
- 서버를 끄려면 터미널에서 `Ctrl + C`.
- 포트가 이미 사용 중이라는 에러가 나면, 이미 켜져 있다는 뜻이니 브라우저만 확인하라고 안내하세요.

**모바일 화면도 꼭 확인하라고 알려주세요.**
브라우저에서 `F12` → 좌측 상단 휴대폰 아이콘 → iPhone 등을 선택하면 모바일 화면으로 볼 수 있습니다.
